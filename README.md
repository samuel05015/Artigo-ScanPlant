# Artigo ScanPlant

Repositório com os arquivos-fonte e a versão final em PDF do artigo sobre o sistema ScanPlant.

## Conteúdo

- `artigo_scanplant.tex`: fonte principal em LaTeX;
- `artigo_scanplant.pdf`: versão final compilada;
- `figuras/`: imagens utilizadas no artigo.

## Compilação

Com uma distribuição LaTeX instalada, execute duas vezes:

```bash
pdflatex artigo_scanplant.tex
pdflatex artigo_scanplant.tex
```
